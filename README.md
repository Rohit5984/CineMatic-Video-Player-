## 🎥 Usage

1. Launch **Cinematic Video Player**.
2. Click **Open Video** or drag and drop a video file into the app.
3. Use the playback controls to play, pause, seek, adjust volume, or enable fullscreen.

### Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| Play / Pause | `Space` |
| Seek forward | `→` |
| Seek backward | `←` |
| Volume up | `↑` |
| Volume down | `↓` |
| Fullscreen | `F` |
| Mute | `M` |
